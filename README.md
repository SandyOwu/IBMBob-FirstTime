# IBMBob-FirstTime

Hola compañeros! Este es un repositorio de prueba para que puedan probar IBMBob por primera vez. Cuenta con un ejemplo para que lo prueben sin problemas. Cualquier duda o problema pueden preguntarme sin problema por medio del grupo de WhatsApp del taller llamado "Linux".

El proósito de esta prueba es modificar el archivo "index.hmtl" con Bob para que miren su manera de trabajar y ayudar como agente.

Exito compañeros.

## Descarga

Para comenzar, tienen que descargar IBMBob e iniciar sesión, este da 30 días de uso gratis, pero tiene tokens llamados BobCoins que se desgastan con cada uso.

### Link de Bob
https://bob.ibm.com/es


## Pasos a seguir
Después de clonar este repositorio, es necesario abrir la carpeta de archivos con el IDE de IBMBob, este tiene una interfaz casi igual a la de VSCode.

Una vez abierta la carpeta, entran en el archivo "prompt.txt" y copian el contenido del archivo. 

Para usar Bob, pegan el prompt en Bob, una vez que se da enter Bob te pide permisos para modificar el archivo, para más rápido recomiendo darle al botón de dos flechitas.

Cuando Bob haya terminado de modificar, significa que ya está terminado!


## Recomendaciones
- Utilizar prompts en inglés, ya que en español este suele gastar más BobCoins.

- Aceptar todos los permisos para que sea más rápido, pero si deseas entender los cambios, ir de uno en uno.

- Trabajar todo el archivo en IBMBob.
